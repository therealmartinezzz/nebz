# Dizayn ekranları

Canlı dizayn kətanı (claude.ai, sahibinə açıqdır): https://claude.ai/artifact/LqGnLah8o54KCUMWFoH5uq

Bu qovluqdakı (`docs/design/`) `.dc.html` faylları həmin kətanın ixracıdır və **istinad üçündür** — kodda olduğu kimi istifadə edilmir. Onlar Claude Design formatındadır (`<x-dc>` daxilində adi HTML + inline stil); brauzerdə açanda əsasən düzgün görünür, amma runtime faylı (`support.js`) olmadığı üçün kiçik fərqlər ola bilər. Layout, mətn və rəngləri buradan götür.

| # | Fayl | Ekran |
|---|---|---|
| 1 | Main.dc.html | Ssenari seçimi |
| 2 | Call.dc.html | Canlı zəng |
| 3 | Report.dc.html | Zəng hesabatı |
| 4 | Dashboard.dc.html | Şirkət paneli (rəqəmlər nümunədir) |
| 5 | Builder.dc.html | Ssenari yaradıcısı |
| 6 | Operator.dc.html | Operator profili (rəqəmlər nümunədir) |
| 7 | Review.dc.html | Rəhbər yoxlaması |
| 8 | Training.dc.html | Məşqlərim (işçi görünüşü) |

# 06 · Pitch deck strukturu

1-ci turu GPT və Claude oxuyur: bölmə başlıqlarını bal kartının adları ilə eyni yaz, hər iddianı rəqəm və ya sübutla göstər, uzun mətnin yerinə aydın cümlələr.

## Slaydlar
1. **Nəbz** — bir cümlə: AI müştəri ilə xidmət keyfiyyəti məşqi və izah oluna bilən qiymətləndirmə.
2. **İstifadəçi üçün dəyər (25)** — kim (çağrı mərkəzi rəhbəri, QA, operator), bu gün nə pozulur, həll edəndə nə dəyişir.
3. **Necə işləyir** — ssenari → zəng → meyar üzrə bal + sitat → rəhbər qərarı → məşq.
4. **Prototip və AI-ın rolu (30)** — ekran görüntüləri; AI-ın 3 rolu: müştərini oynamaq, standartdan meyar çıxarmaq, sitatla qiymətləndirmək. Demo linki və video.
5. **Keyfiyyət testi (20)** — 16 zəng, AI vs insan uyğunluğu, tutulan tələlər, 2–3 uğursuzluq nümunəsi, vaxt müqayisəsi.
6. **Reallıq (15)** — data tələbi (şirkətin xidmət standartı; real zəng datası tələb olunmur), işləmə xərci (bir zəngin API xərci — real qiymətlərlə hesabla, uydurma), növbəti addım (bir bankla pilot).
7. **Orijinallıq (10)** — müsahibə yox, iş nümunəsi; standarta bağlı izah oluna bilən bal; Azərbaycan dilində səs; insan nəzarəti dizaynda.
8. **Etika və risklər** — emosiya yox davranış; son qərar insanda; etiraz hüququ; sintetik data.
9. **Açıqlama** — modellər, kitabxanalar, data.
10. **Komanda və növbəti addım.**

## Münsiflərin verə biləcəyi suallar
- *AI səhv bal versə?* → Hər bal sitatla göstərilir, etibarlılıq aşağıdırsa rəhbərə gedir, işçi etiraz edir; testdə uyğunluq X%.
- *Operator AI ilə danışdığını bilir, real davranışı ölçürsünüzmü?* → Məşq rejimində bilir; məqsəd bacarığı ölçmək və inkişaf etdirməkdir. Real zəng analizi növbəti mərhələdir.
- *Azərbaycan dilində səs nə qədər yaxşıdır?* → Test nəticəsini dürüst göstər; mətn rejimi ehtiyatdır.
- *Bu, işçiləri izləmə alətidir?* → Xeyr: ballar məşq üçündür, avtomatik cəza yoxdur, işçi öz nəticələrini görür.
- *Rəqiblər?* → Gizli müştəri agentlikləri (bahalı, az əhatə), çağrı analitikası platformaları (mövcud zəngləri analiz edir, məşq etdirmir). Rəqib adlarını deck-ə yazmazdan əvvəl internetdə yoxla.
- *Bir zəng neçəyə başa gəlir?* → Real API qiymətlərindən hesabla.
- *Kim alacaq, necə satacaqsınız?* → Çağrı mərkəzi rəhbəri; operator başına aylıq abunə; ilk addım pilot.
